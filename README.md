# smart warehouse operations & order fulfillment system

Build a polished Smart Warehouse Operations & Order Fulfillment Platform using mock data.

Include: inventory monitoring, order management with priority scoring, smart inventory allocation, picking/packing workflow, low-stock alerts, damaged/missing item handling, dispatch tracking, and analytics.

Core workflow:
Order → Priority → Inventory Check → Smart Allocation → Picking → Packing → Quality Check → Dispatch → Inventory Update

Make the system decision-driven, not just CRUD. For shortages, automatically decide which orders get stock based on priority/urgency and suggest actions like partial fulfillment, backorder, or reorder.

Create a modern, responsive dashboard with clear KPIs, alerts, order status tracking, inventory views, exception handling, and useful analytics. Use realistic sample warehouse data and focus on excellent UX and edge cases.
